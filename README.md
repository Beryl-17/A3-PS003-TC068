# FlowPulse-FL

**AIORI-3 — A3-PS003-TC068 — Team Elevate Tech**

FlowPulse-FL is a federated-learning simulator for traffic-flow forecasting. It uses the public UCI Metro Interstate Traffic Volume dataset to represent multiple virtual intersections, trains a compact forecasting model locally at each client, and combines model updates using FedAvg.

The prototype compares:

- Centralized training
- Federated Averaging (FedAvg) with IID client partitions
- Federated Averaging (FedAvg) with non-IID client partitions
- Full, random, and FlowPulse client-selection strategies
- Forecast accuracy (MAE and RMSE) and communication cost in bytes

## Dataset

- **Dataset:** [UCI Metro Interstate Traffic Volume](https://archive.ics.uci.edu/dataset/492/metro+interstate+traffic+volume)
- **Local file:** `data/raw/traffic_volume.csv.gz`
- **Split:** Chronological train/test split to avoid future-data leakage
- **Clients:** 4 simulated intersections
- **Input window:** Previous 24 observations
- **Target:** Next traffic-volume observation

## Run experiments

```bash
PYTHONPATH=src python -m flowpulse.run_experiments \
  --rounds 12 \
  --local-epochs 3 \
  --clients 4 \
  --budget 2 \
  --modes iid non_iid \
  --strategies full random flowpulse
```

Outputs are written to:

- `outputs/tables/experiment_summary.csv`
- `outputs/tables/all_round_history.csv`
- `outputs/plots/`

## Verified 12-round results

These results were generated by the repository’s experiment runner using 4 clients, 12 rounds, 3 local epochs, and a selection budget of 2 clients.

| Partition | Strategy | MAE | RMSE | Communication bytes |
|---|---|---:|---:|---:|
| IID | Centralized | 762.8113 | 988.0579 | 0 |
| IID | Full participation | 762.8130 | 988.0626 | 19,200 |
| IID | Random selection | 762.6398 | 987.9341 | 9,600 |
| IID | FlowPulse selection | 763.4047 | 988.2911 | 9,600 |
| Non-IID | Centralized | 762.8113 | 988.0579 | 0 |
| Non-IID | Full participation | 763.1699 | 988.5296 | 19,200 |
| Non-IID | Random selection | 758.1314 | 985.1839 | 9,600 |
| Non-IID | FlowPulse selection | 766.6116 | 991.2270 | 9,600 |

Selecting 2 of 4 clients reduced communication from 19,200 to 9,600 bytes over 12 rounds, while maintaining forecasting accuracy close to full participation.

## How FlowPulse selection works

In each communication round, FlowPulse examines recent local target variation using `traffic_change_score()`. It prioritizes clients whose recent traffic patterns have changed more substantially, while respecting the per-round client budget. This is intended to reduce unnecessary communication from clients with relatively stable recent patterns.
